================================================================================
                            KEY PATTERNS & CONVENTIONS
================================================================================

1. COMPONENT PATTERNS
   - Functional components with Hooks (exclusive)
   - ErrorBoundary is only class component (required for error boundaries)
   - Compound components with Radix Slot pattern
   - Custom hooks for reusable logic extraction

2. DATA FETCHING
   - Custom hooks wrapping API client (useScan, useTicket)
   - Mock implementations in api/client.ts (Phase 4: real API)
   - Local state management with scan-store.ts
   - React Query installed but not yet implemented

3. FORM HANDLING
   - React Hook Form + Zod validation (exclusive pattern)
   - @/components/ui/form wraps Radix UI primitives
   - Consistent FormField, FormItem, FormLabel, FormControl, FormMessage pattern

4. STATE MANAGEMENT
   - Redux Toolkit for global state (auth, ui, auditLog)
   - Typed hooks: useAppDispatch, useAppSelector
   - Local component state with useState/useReducer
   - Custom hooks for feature-specific state

5. AUTHENTICATION & AUTHORIZATION
   - Mock authentication with 4 roles: super-admin, admin, user, viewer
   - RBAC with 15+ permissions (PERMISSIONS matrix)
   - ProtectedRoute component with role + permission checks
   - localStorage persistence for auth token and user data
   - Super-admin bypass for all permissions

6. STYLING APPROACH
   - Tailwind CSS + CSS custom properties (hybrid)
   - CSS variables for theming (--bg-primary, --text-primary, etc.)
   - Class Variance Authority (CVA) for component variants
   - Forced light mode (color-scheme: light)
   - Terminal/hacker aesthetic for login page

7. ERROR HANDLING
   - Local error state in components (useState)
   - ErrorBoundary for component tree errors
   - Redux slice error state for async operations
   - Toast notifications via Sonner library
   - Try-catch blocks in async functions

8. CODE ORGANIZATION
   - Feature-based folder structure
   - Path alias: @/ → ./src/
   - Co-located test files (.test.tsx)
   - Named exports for components
   - JSDoc comments for documentation

9. ROUTING
   - React Router v7 with nested routes
   - Dashboard layout with Outlet component
   - Public routes: /, /login
   - Protected routes under /dashboard/*
   - Dynamic routes: /scans/:id, /tickets/:id

================================================================================
                            ROUTE STRUCTURE
================================================================================

Public Routes:
  /                           → Index (Landing Page)
  /login                      → Login

Protected Dashboard Routes (require authentication):
  /dashboard                  → DashboardIndex (overview)
  
  /dashboard/scans
    /all                       → AllScans
    /new                       → NewScan
    /:id                       → ScanDetail
    /:id/progress              → ScanProgress
    /:scanId/results/:vulnId  → ScanResultDetail
    /my-scans                  → MyScans
    /trash                     → TrashScans
  
  /dashboard/templates         → Templates
  /dashboard/users             → UserManagement
  /dashboard/reports           → Reports
  /dashboard/settings          → Settings
  /dashboard/logs              → LogViewer
  
  /dashboard/tickets
    /                          → TicketList
    /new                       → CreateTicket
    /:id                       → TicketDetail
